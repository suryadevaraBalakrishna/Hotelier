# Hotelier - Hotel Booking Website

A full-stack Hotel Booking web application built using the MERN stack. This platform allows users to search hotels by location, view available rooms, make hotel bookings, and securely complete payments using Razorpay.

## 🚀 Live Demo

[https://hotelier-website-mu.vercel.app/](https://hotelier-website-mu.vercel.app/)

## 📌 Features

- 👤 User Registration & Login
- 🔐 User Authentication using JWT
- 🏨 Hotel Listing and Hotel Details
- 📍 Search Hotels by Location
- 🛏️ Room Listing and Room Details
- 📅 Hotel Room Booking
- 👥 Guest and Booking Details
- 💳 Online Payment Integration using Razorpay
- ✅ Payment Verification
- 📋 Booking Status Management
- 👤 User Dashboard
- 🖼️ Image Upload and Management
- ☁️ Cloudinary Image Storage
- 🔧 Admin Panel for Hotel Management
- 🏨 Admin Hotel CRUD Operations
- 🛏️ Admin Room CRUD Operations
- 👥 Admin User Management
- 📊 Booking Management
- 📱 Fully Responsive UI
- 🔗 RESTful API Integration

## 💳 Payment Integration

- Integrated Razorpay for secure online hotel booking payments
- Creates Razorpay payment orders through the backend
- Handles Razorpay payment verification
- Updates booking status after successful payment
- Provides a seamless checkout experience

Room Images
Slider Images
Team Images
About Images
User Profile Images
Website Logo
